# 📌 2) Hard Metric (HM / IEC 61076-4-101)

If you need **higher density AND low profile**, you might want to step off classic DIN.

These families were designed for:
- **CompactPCI**
- Higher pin counts (200+ pins)
- **Lower overall module thickness**

Because they use **2.0 mm pitch vs 2.54 mm**, they’re physically smaller and easier to keep low profile, and vendors offer multiple stack heights.

---

# 📌 3) Right-Angle (RA) Low-Profile Versions

Right-angle styles *by definition* reduce height in one axis. Some vendors sell RA variants specifically labelled as:
- **Low-Profile Right-Angle DIN**
- **Reduced stack height RA**

This can save space in:
- z-axis (thickness)
- backplane clearance envelope

These options often look like heavy plated SMT / press-fit bodies with minimal extruded plastic housing.

---

# 🧩 When “low profile” really matters
There are *two* useful measures:

### ➤ **A) Vertical thickness**
Distance from PCB surface to the mating plane.
- Classic DIN 41612: ~14–16 mm or more
- Low-profile variants: ~8–11 mm

### ➤ **B) Horizontal bulk behind PCB**
How much the connector protrudes into the forbidden zone (your “yellow rectangle”).
- Standard housings: fairly deep
- Low-profile / RA: significantly reduced

If you need **freeing a 25 mm envelope**, a low-profile RA variant might be enough.

# 1️⃣ Vertically Stacked (Multiple Connectors on Same Card Edge)

This is common in **VME, CompactPCI, telecom shelves**, etc.

You place two (or more) backplane connectors on the same PCB edge, one above the other.

- J1 + J2 in entity["technology_standard","CompactPCI","industrial computer bus"]

### What it looks like:

**Pros**
- Maintains standard backplane compatibility
- Scales pin count (96 + 96, 110 + 110, etc.)

**Cons**
- Increases insertion force
- Requires precise guide rail alignment
- Needs careful power sequencing if split

---

# 2️⃣ Multi-Module / Ganged Connectors

Some manufacturers (ERNI, TE, Harting) allow you to:
- Combine connector modules side-by-side
- Combine power + signal blocks
- Create a “custom stacked” frame

This is common in Hard Metric families (IEC 61076-4-101).

You can build:
- 5-row signal + 2-row power
- Differential pair zones separated by grounds
- Mixed voltage domains

This is mechanically cleaner than trying to stack DIN bodies.

---

# 3️⃣ Board-to-Board Stacking (Mezzanine on Backplane)

Different concept — but sometimes what people mean:

You mount:
- Backplane connector
- Then stack a second board above it using mezzanine connectors

That effectively creates a stacked architecture without stacking the backplane connector itself.

Very useful if:
- Your yellow connector conflict is height-related
- You need to move functionality vertically instead of horizontally

---

# 4️⃣ True “Double-Deck” Connector Bodies

These do exist in some connector families (mostly not classic DIN 41612):

They look like:
- Two mating interfaces in one molded housing
- One above the other
- Shared press-fit tails

These are more common in:
- Hard Metric
- AirMax / MultiGig RT
- High-density telecom backplanes

You won’t typically find this in classic 2.54 mm DIN 41612.
