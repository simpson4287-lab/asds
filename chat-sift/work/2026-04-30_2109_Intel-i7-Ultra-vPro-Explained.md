[M3] AI (2026-04-30 21:09):
They’re **three separate things**:

**Intel Core i7** = performance tier.  
Traditionally: i3 / i5 / i7 / i9. An i7 is usually a higher-performance mainstream CPU, but the exact speed depends heavily on generation, power limit, cooling, and laptop design.

**Intel Core Ultra / Ultra 7** = newer naming and architecture.  
“Ultra” is Intel’s newer branding for AI-PC-era chips. The key additions are usually:

- **NPU**: a neural processing unit for local AI tasks, video-call effects, background blur, noise suppression, etc.
- **Better integrated graphics**, often Intel Arc on suitable models.
- **Hybrid CPU design**: performance cores + efficiency cores.
- Often better battery/performance balance than older Core i-series chips, depending on model. Intel describes Core Ultra as having CPU, GPU and NPU engines for AI workloads. citeturn969596search0turn969596search2

So **Core Ultra 7** is broadly the modern equivalent tier to **Core i7**, but not automatically faster than every older i7. You compare exact CPU models.

**Intel vPro** = business/IT management platform, not raw speed.  
vPro machines are aimed at company fleets. The main benefits are:

- remote management, including out-of-band support in supported configurations;
- hardware-based security features;
- platform validation/stability for business deployment;
- easier maintenance for IT departments. citeturn969596search1turn969596search5

For a normal personal laptop, **vPro is not especially useful** unless you specifically need corporate manageability or your workplace IT requires it. It does not mean “faster i7”. It means “business-manageable platform”.

So in plain English:

**“Intel Core Ultra 7 vPro”** means:  
a modern high-mid/high-end Intel laptop CPU tier, with AI/NPU features, sold in a business-class platform that supports enterprise management/security.

For you, buying a work/design laptop, I’d read it like this:

**Good signs:** Ultra 7, 32 GB RAM, decent SSD, good cooling, business chassis, Thunderbolt, strong battery.  
**Do not overpay just for:** vPro, unless it is a company-managed laptop.  
**Check carefully:** exact processor code, e.g. Ultra 7 155H, 165U, 265V, etc. The suffix matters a lot.

**Core Ultra 7 165H** is a decent modern laptop CPU. It is a **Meteor Lake H-series** part, so it is the higher-power laptop class rather than the lower-power “U” class.

Key specs:

| Item | Core Ultra 7 165H |
|---|---:|
| Cores / threads | **16 cores / 22 threads** |
| Core layout | **6 performance + 8 efficiency + 2 low-power efficiency** |
| Max turbo | **5.0 GHz** |
| Cache | **24 MB** |
| Base / turbo power | **28 W base, up to 115 W turbo** |
| Graphics | **Intel Arc integrated graphics** |
| AI/NPU | Yes, Intel AI Boost / NPU |
| vPro | Yes, often sold as a business/manageability SKU |

Intel lists it as a **16-core, 22-thread mobile processor with Intel Arc graphics, 24 MB cache, 5.0 GHz max turbo, 28 W base power and 115 W max turbo power**. citeturn409925search0turn409925search7

In practical terms: **good CPU**. For office, Teams, lots of browser tabs, Excel, Word, light CAD, Altium schematic/layout, and general engineering work, it should be more than capable. The important bit is that **165H is the H-series version**, so it has more performance headroom than something like an Ultra 7 **165U**, assuming the laptop cooling is decent.

The main caveat: laptop implementation matters. A thin business laptop with the same 165H can throttle earlier than a chunkier machine with better cooling. So I’d look at:

**32 GB RAM minimum** for your kind of work.  
**1 TB SSD** if available.  
Good cooling / business workstation chassis.  
Screen quality and ports.  
Whether the RAM is soldered and non-upgradeable.

The **vPro** part is not the reason to buy it personally. It is mainly useful for IT management/security in company fleets. The **165H itself** is the useful bit.

[M14] AI (2026-04-30 22:28):
In **PDF-XChange Editor**, add a watermark like this:

1. Open the PDF.
2. Go to **Organize** tab.
3. Select **Watermarks**.
4. Choose **Add**.
5. Pick either:
   - **Text Watermark** — e.g. “DRAFT”, “CONFIDENTIAL”
   - **File/Image Watermark** — for a logo or image
6. Set the options:
   - **Page range**: all pages or selected pages
   - **Position**: centre, top, bottom, etc.
   - **Rotation**: often 45° for “DRAFT”
   - **Opacity/transparency**: lower it so the document remains readable
   - **Scale**: size of the watermark
7. Click **OK** / **Apply**.
8. Save the PDF.

A good typical setting for a draft mark is:

**Text:** DRAFT  
**Position:** Centre  
**Rotation:** 45°  
**Opacity:** around 15–30%  
**Font size:** large enough to span the page  

In some versions it may be under:

**Document → Watermarks → Add**

rather than the **Organize** ribbon.
