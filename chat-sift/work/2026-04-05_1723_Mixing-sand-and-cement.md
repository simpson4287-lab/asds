How wet can you mix sand and cemebt

[M2] AI (2026-04-05 17:23):
As wet as needed to make it workable, but **not so wet that it goes sloppy or shiny with free water**.

For a normal sand/cement mortar mix, aim for:

- **Damp to plastic**, not runny
- It should **hold its shape on a trowel**
- When squeezed, it should **stay together**
- It should **not ooze water**

Too wet causes:

- weaker final strength
- more shrinkage and cracking
- slumping
- poor adhesion on vertical work

A good rule is:
- add water **slowly**
- stop when the mix becomes **smooth and workable**
- if it starts looking like a thick slurry, it’s too wet

For typical mortar, you usually want it like:
- **bricklaying / pointing:** fairly soft but still holds on the trowel
- **bedding / patching:** a bit stiffer
- **rendering:** workable but not saggy

If you’ve overwatered it slightly, add a bit more dry sand/cement in the same ratio to bring it back. If it’s gone very soupy, it’s often better to start again.
