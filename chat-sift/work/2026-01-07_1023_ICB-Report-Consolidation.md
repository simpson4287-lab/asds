[M14] AI (2026-01-07 10:41):
In Word (and most similar editors), an asterisk auto-bullets because it is treated as a list trigger. To insert an asterisk **without** creating a bullet, use one of the following methods.

### Quick, reliable methods

1. **Type a space first**  
   Press **Space**, then type `*`, then continue typing.  
   The editor will not interpret it as a bullet trigger.

2. **Use Ctrl + Z immediately**  
   If Word auto-formats it into a bullet:
   - Press **Ctrl + Z** once  
   - The asterisk remains as a normal character

3. **Disable automatic bulleted lists (recommended for long documents)**  
   - Go to **File → Options → Proofing**  
   - Select **AutoCorrect Options…**  
   - Open the **AutoFormat As You Type** tab  
   - Untick **Automatic bulleted lists**  
   This prevents `*`, `-`, and `1.` from triggering bullets entirely.

### Inline asterisk (for footnotes or emphasis)

- Type the text first, then insert `*` **mid-sentence**, not at the start of a line.
- Or type another character first (e.g. `_` or `(`), then delete it after adding the `*`.

### Best practice for reports like yours

For ICB or governance documents, consider:
- Using **superscript numbers** (¹²³) instead of asterisks, or  
- Using **[Note:]** or **(see note below)** for clarity and audit-friendliness.
