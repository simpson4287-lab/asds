[M2] AI (2026-04-19 12:55):
Yes — that overhang is getting into the “could become annoying” zone, especially once you repeat it up to 10 layers.

What I’d be watching for is not catastrophic failure so much as:

- **board bowing/sagging at the unsupported end**
- **the stack becoming tippy** if one layer is not sitting flat
- **paint transfer / sticking** where boards touch battens or each other
- **edge chipping** if one slips while stacked

From the photo, that top board looks to have a fair bit of unsupported length relative to its thickness. One board on its own is probably fine for a while, but **10 repeats** means the small deflection and instability adds up.

My view: **I would reduce the overhang if you can.**

Best approach:
- keep the overhang to a **small amount only**, just enough for handling and painting the edge
- put **another support nearer the free end**
- make sure each layer’s supports are **vertically aligned** so weight travels straight down
- use **spacers/stickers all in the same positions** between layers
- avoid letting a board sit with its full weight on a freshly painted face

A practical rule here: if you can press the overhanging end and see any noticeable spring, it is too much for a 10-high painted stack.

Safer setup:
- **3 support lines** instead of 2 for each board lengthwise
- or **flip the board orientation** so less length hangs out
- or stack fewer at a time, maybe **3–5 high**

Also, because you’re painting:
- use thin sacrificial spacers so boards do not seal themselves together
- let each face go tack-free before building height
- keep the stack dead level, otherwise the top few can creep

So: **for one or two boards, probably tolerable; for ten repeated layers, I’d call that overhang more than ideal and worth correcting.**

A simple fix is to add one more timber near the outer end. That would make the whole thing much more trustworthy.

A few things still matter:

**1. Watch the end support blocks**  
The little packers at the corners and ends want to be sitting solid and all at similar height. If one is proud, that board can rock and crack an edge.

**2. Keep spacer positions repeated vertically**  
Ideally every layer has spacers in the same places, one above another, so the load goes straight down through the stack rather than point-loading random spots.

**3. Don’t let those long top battens mark the paint**  
Those rails on top are useful as restraint/weight, but if the paint is still soft they can print into the surface. Best if they only bear on sacrificial spacer pads, not directly on the painted face.

**4. Don’t go too high if the stack starts wandering**  
Even if 10 is possible, I’d still be happier around **5–6 high per stack** unless it stays very flat and calm. Cement board edges can chip if one sheet shifts.

**5. Wet ground / splashback**  
You’re outdoors on what looks like damp tarmac. Fine for a short stint, but don’t let the lower boards sit where spray, puddling, or runoff can keep one face wetter than the other for ages.

Overall: **yes, this version looks acceptable** and much more sensible than the first setup.

Only thing I’d still improve: use **uniform thin spacers** instead of mixed random offcuts where possible. That will make drying, flatness, and stack stability more predictable.
