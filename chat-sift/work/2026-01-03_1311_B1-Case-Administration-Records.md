## **B1 – Case Administration & Records**

**Purpose**  
To act as the authoritative administrative index for the case. This layer captures all official correspondence, references, and procedural acknowledgements exactly as received. It contains no interpretation, narrative, or analysis.

**Scope (What Belongs Here)**  
This layer is limited strictly to administrative and record-keeping material.

- Police correspondence (emails, letters, notices)  
- Court correspondence (summons, hearing notices, directions)  
- Rights of Access acknowledgements and responses  
- Case reference numbers (crime ref, custody ref, court ref)  
- Disclosure confirmations and acknowledgements  
- Deadlines, dates, and response windows as formally stated  
- Proofs of submission (screenshots, confirmations, receipts)

**Exclusions (What Must Not Appear Here)**  
- No factual narrative of the incident  
- No evidence content (CCTV, interviews, statements)  
- No mental health or contextual explanation  
- No personal commentary, inference, or strategy  
- No duplication of documents stored in other layers

**Formatting Rules**  
- Items logged in chronological order (oldest → newest)  
- Each entry should include:
  - Date issued  
  - Issuing body (Police / Court / CPS / Other)  
  - Document type  
  - Reference number(s)  
  - Action required (if any)  
  - Deadline (if stated)
- Verbatim transcription only where summarisation would risk distortion

**Status Within Project B**  
- This layer is **procedurally authoritative**  
- If a deadline or reference is not recorded here, it is treated as not existing for the case  
- Other layers may reference B1, but B1 never references other layers

**Versioning**  
- Managed in lockstep with all Project B layers  
- Changes only occur when new official material is received or corrected
