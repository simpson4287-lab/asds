## Option 1 — Apple Devices for Windows (Best official method)
image_group{"query":["Apple Devices for Windows iPhone files","iPhone Windows File Explorer DCIM","Apple Devices app Windows iPhone"],"aspect_ratio":"16:9"}

**Best for:** Photos, videos, basic file access, backups  
**Cost:** Free  
**Completeness:** High (media + backup)

### Steps
1. Install **Apple Devices** from the Microsoft Store (replaces iTunes).
2. Connect iPhone via USB.
3. Unlock iPhone → tap **Trust This Computer**.
4. Open **File Explorer → This PC → Apple iPhone**.
5. Copy everything inside **DCIM** (all photos & videos).
6. (Optional) Use **Apple Devices → Back Up Now** for a full device backup.

### Notes
- DCIM contains *all camera content*, including edited videos.
- App data is **not** directly browsable, but **is included** in backups.
- This is the cleanest Apple-supported route.

## Option 2 — iCloud for Windows (Set-and-forget sync)
image_group{"query":["iCloud for Windows Photos sync","iCloud Drive Windows File Explorer","iCloud Windows settings photos"],"aspect_ratio":"16:9"}

**Best for:** Ongoing sync, no cables  
**Cost:** Free (storage limits apply)  
**Completeness:** Medium–High

### Steps
1. Install **iCloud for Windows**.
2. Sign in with Apple ID.
3. Enable:
   - **Photos**
   - **iCloud Drive**
4. Files appear in:
   ```
   C:\Users\<you>\iCloudDrive
   ```

### Notes
- Slower initial sync if you have years of photos.
- Requires sufficient iCloud storage.
- Very reliable long-term.
