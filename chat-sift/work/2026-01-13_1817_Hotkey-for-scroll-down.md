Short version: it depends what you’re using, but there are a few universal classics.

On **Windows**:
- **Page Down** → scrolls down one screen
- **Space** → scrolls down one screen (works in browsers, PDFs, many apps)
- **Arrow Down** → nudges down line by line
- **Ctrl + Arrow Down** → jumps by paragraphs or sections in some apps

On **macOS**:
- **Fn + Down Arrow** → Page Down equivalent
- **Space** → scrolls down one screen (Safari, Chrome, PDFs)
- **Arrow Down** → small step down

In **browsers specifically** (Windows & Mac):
- **Space** → page down
- **Shift + Space** → page up

[M4] AI (2026-01-13 18:17):
In **Microsoft Teams chat**, the behaviour is a bit… opinionated. Here’s the clean truth.

**Windows**
- **Page Down** → scrolls the chat down one screen  
- **Page Up** → scrolls up one screen  
- **Ctrl + End** → jumps straight to the latest message (very useful)
- **Arrow Down** → slow, line-by-line scroll
- **Space** → *usually does nothing* in chat (unlike browsers)

**macOS**
- **Fn + Down Arrow** → Page Down (scrolls one screen)
- **Fn + Up Arrow** → Page Up
- **⌘ + Down Arrow** → jumps to the latest message
- **Arrow Down** → small scroll

**Mouse / trackpad**
- Scroll wheel or two-finger scroll is still the most reliable
- Clicking inside the message history pane matters—if focus is in the text box, some keys won’t work

One subtle gotcha: Teams only honours these shortcuts when the **message list has focus**. If your cursor is blinking in the compose box, Page Down may appear “broken”.

The fastest workflow, once you know it, is **Ctrl + End / ⌘ + ↓** to snap back to “now”, then scroll up selectively. Teams is less a chat app and more a time-travel simulator with opinions.
